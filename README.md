# fundamentos-js-bryan-rojas
# Fundamentos de programación con JavaScript

Autor: Brayan Alberto Rojas Gallo

Práctica de entrega del Bloque 1: cinco ejercicios preliminares y un ejercicio obligatorio que simula el pedido de una tienda online en consola.

## Requisitos

Tener instalado Node.js

## Cómo ejecutar los ejercicios

Desde la carpeta raíz del repositorio:

| Ejercicio | Descripción | Comando |
|---|---|---|
| 1. Ticket de un producto | Calcula el subtotal, el IVA y el total de un producto | `node ejercicio-1/ticket.js` |
| 2. Descuento y envío | Aplica el descuento y los gastos de envío según el importe | `node ejercicio-2/descuento-envio.js` |
| 3. Explorar el catálogo | Muestra el catálogo, los agotados, el más caro y el valor del inventario | `node ejercicio-3/catalogo.js` |
| 4. Buscar un producto | Busca un producto por su nombre y muestra sus datos | `node ejercicio-4/buscar.js` |
| 5. Refactorizar en funciones | Funciones reutilizables de los ejercicios 1 a 4 | `node ejercicio-5/funciones.js` |
| Obligatorio: tienda online | Procesa un pedido, genera el ticket y actualiza el stock | `node obligatorio/tienda.js` |
